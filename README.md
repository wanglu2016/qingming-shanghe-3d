# 入画 · 清明上河

**作者：王路**

取意张择端《清明上河图》宋本的浏览器三维汴京。以绢本暖色、淡彩和墨线，连接郊野、虹桥、汴河码头、街市与城门，玩家可以自由行走，也可以乘船看两岸。

## 玩法

- **览卷**：拖动画面旋转，滚轮或双指缩放。
- **漫游**：WASD / 方向键行走，拖动画面转向，Shift 快行。
- **E**：与附近人物交谈、登船或下船。
- **M**：打开舆图；**V**：切换视角；**Esc**：关闭弹窗。
- 点击画面下方地名，可快速前往五处景点；到达后记录足迹。
- 手机提供触屏方向键。设置中可减少动态效果、调整画面精细度，并开启合成声景。

## 本地运行

不需要构建，Three.js 已包含在 `vendor/` 中。在仓库目录启动任意静态 HTTP 服务，例如：

```bash
python3 -m http.server 8000
```

然后在支持 **WebGL 2** 的浏览器中打开 `http://localhost:8000/`。直接双击 HTML 可能因浏览器的模块加载限制而无法运行。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 界面与入口 |
| `world.js` | 三维场景、程序化建模、行人、河船、导航与交互 |
| `style.css` | 绢本风格界面与手机适配 |
| `vendor/` | Three.js 及几何合并工具，含第三方许可证 |

场景几何、纹理、店铺招牌与声景由源码生成，随机种子固定。中文网页字体提供系统字体回退。

## 创作与验证

这是依据宋本视觉元素重新组织空间的三维游园，未作原画建筑布局的逐尺复原，也未使用原画扫描图作为场景贴图。

已对真实 Three.js 场景图完成构建、几何数值、五处出生点、完整桥面通行、主街与城门通行、河岸碰撞、足迹记录、登船与下船的逻辑检查。制作环境的预览浏览器禁用了 WebGL，因此该环境中未完成 GPU 实景渲染与键盘漫游的视觉验证。
